## 📱 PWA Mobile Foundation & Offline Sync Core (LIVE)

Sikander OS is fully installable as a standalone native-like Progressive Web App (PWA) on **Android (Google Chrome)** and **iOS (Safari)** with zero app store dependencies and complete offline autonomy.

### Key Capabilities:
- **Standalone PWA Installation**:
  - Web App Manifest (`manifest.json`) configured with standalone display, obsidian/cyan theme, and deep shortcuts to Cinema, Property, and Music.
  - High-resolution SVG (`icons/icon.svg`) and crisp 192x192 and 512x512 standard & maskable PNG icons.
  - In-app 1-click install banner on mobile and desktop browsers with iOS Safari guidance.
- **Tiered Service Worker Caching (`sw.js`)**:
  - **Cache-First**: Pre-caches HTML shells, CSS, JS, fonts, and icons for sub-second offline launches.
  - **Stale-While-Revalidate**: Instant rendering for JSON catalogs (`data/*.json`) while background-fetching updates.
  - **Offline Station Fallback (`offline.html`)**: Branded obsidian/cyan offline interface with cached module links and auto-reconnection.
- **Local-First Multi-Device Sync Engine (`data/sync_engine.js`)**:
  - Unified local storage repository (`localStorage` + `IndexedDB`).
  - **1-Click JSON Snapshot Export/Import**: Easily backup or sync watchlists, ratings, privacy state, and telemetry across Home PC, Work PC, and Mobile without cloud subscriptions.
  - Complete architecture manual: [`data/MULTI_DEVICE_SYNC_GUIDE.md`](data/MULTI_DEVICE_SYNC_GUIDE.md).
- **Mobile Touch Navigation**:
  - Floating glassmorphism bottom navigation bar (`⚡ Home`, `🎬 Cinema`, `🏢 Property`, `🎵 Music`, `🔄 Sync`).
  - Minimum 44x44px touch-friendly tap targets and safe-area notch support (`viewport-fit=cover`).
